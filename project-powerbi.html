Power BI: Beginner DAX Measures

Before jumping into visualizations, I wanted to understand how DAX calculates numbers. Here are the basic measures I wrote to track overall performance in a mock dataset.

// Measure 1: Calculate Total Revenue
Total Revenue = SUM('Sales'[Revenue])

// Measure 2: Count Unique Customers to see foot traffic
Unique Customers = DISTINCTCOUNT('Sales'[CustomerID])

// Measure 3: Find the Average Order Value
Average Order Value = DIVIDE([Total Revenue], [Unique Customers], 0)
