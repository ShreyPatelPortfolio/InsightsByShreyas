SQL Basics: Querying Retail Sales

Here is a snippet from my first SQL practice session. I wanted to see how to group data and find total sales per region using a basic SELECT and GROUP BY statement.

-- Select the region and calculate the total sales volume
SELECT 
    Region,
    COUNT(OrderID) AS Total_Orders,
    SUM(Sales_Amount) AS Total_Revenue
FROM 
    retail_sales_data
WHERE 
    Status = 'Completed'
GROUP BY 
    Region
ORDER BY 
    Total_Revenue DESC;
