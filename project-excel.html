Excel Dashboard: Monthly Sales Tracker

I wanted to see what it actually takes to build a proper dashboard in Excel from scratch — not just a table with some formatting. So I created a monthly sales tracker with Pivot Tables, XLOOKUP, and conditional formatting to highlight performance dips. This taught me how the pieces fit together and how to design something a manager could actually use.

Excel Pivot Tables XLOOKUP Conditional Formatting Charts Named Ranges
📋 What this project is: A single-file Excel workbook built to track monthly sales performance across regions and products. I designed it to look like something you'd actually hand to a manager — KPI summary at the top, dynamic charts, color-coded performance cells. The formulas below are the real ones from the file. The workbook is in the GitHub repo.

Key Formulas Used

These are the actual formulas from the workbook. I documented each one because I kept forgetting what they did when I came back to the file.

Excel Formulas sales_tracker.xlsx
XLOOKUP — Pull product name from product table
=XLOOKUP(B2, Products[ProductID], Products[ProductName], "Not Found")
Used XLOOKUP instead of VLOOKUP because it can search left-to-right or right-to-left and doesn't break when columns are added.
SUMIFS — Revenue for a specific month and category
=SUMIFS(Orders[SalePrice], Orders[Month], $A2, Orders[Category], B$1, Orders[Status], "<>Returned")
This powers the pivot table alternative — filters by month, category, and excludes returns all in one formula.
IFERROR — Prevent ugly #DIV/0! errors
=IFERROR(SUM(D2:D13)/COUNT(D2:D13), 0)
Wrapping calculations in IFERROR means empty months show 0 instead of a red error cell.
MoM % Change — Month-over-month growth
=IFERROR((C3-C2)/C2, 0)
Simple but powerful. Formatted as percentage. Conditional formatting then colors positive green, negative red automatically.
COUNTIF — Count orders above average value
=COUNTIF(Orders[SalePrice], ">"&AVERAGE(Orders[SalePrice]))
Concatenating ">" with AVERAGE was a trick I found after trying and failing to make it work with a static number.

What I Learned

🔍
XLOOKUP > VLOOKUP
VLOOKUP breaks if you insert a column. XLOOKUP searches by column name, handles errors gracefully, and works in both directions. I'm not going back.
🎨
Conditional Formatting = automated alerts
Setting rules to highlight cells below threshold meant the dashboard flags problems without anyone having to look for them. That's the whole point.
📛
Named Ranges save sanity
Naming my data tables made formulas readable. "Orders[SalePrice]" is infinitely clearer than "$D$2:$D$1847" — especially when revisiting the file a week later.
🔄
Pivot Tables need clean source data
My first pivot returned garbage because the source had inconsistent category names ("jackets" vs "Jackets"). Data cleaning before analysis is not optional.
