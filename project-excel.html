Excel: Data Cleaning Practice

This project focused on taking raw, messy data and making it usable. Instead of a screenshot, here are the exact formulas and logic I used to clean the dataset.

Functions Used:

  • Standardizing Names: Used =PROPER(TRIM(A2)) to fix messy capitalizations and extra spaces in customer names.
  • Extracting Dates: Used =TEXT(B2, "YYYY-MM") to group daily transactions into monthly buckets for easier pivot table analysis.
  • Merging Tables: Used =XLOOKUP(C2, Products!A:A, Products!B:B, "Not Found") to pull in product categories from a separate sheet safely without breaking if columns move.
